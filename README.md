# Block District

Локальная песочница на Babylon.js + TypeScript + Vite. Интернет во время игры не нужен:
геометрия, персонаж и анимации находятся в проекте.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Нужны браузер с WebGL и клавиатура с мышью.
`npm run build` — сборка, `npm run preview` — просмотр сборки.
`npm test` — проверка импорта карты и движения/коллизий. Для тестов нужен Node.js 24+.

## Игра

- WASD — движение относительно камеры, Shift — бег, Space — прыжок.
- ЛКМ + движение мыши — поворот камеры, колесо — расстояние.
- R — вернуть игрока на старт, Tab — переключить игру и редактор.
- Падение с края карты возвращает игрока на старт.

## Редактор

- Клик по коробке выбирает объект. Манипуляторы меняют положение, поворот вокруг мировой оси Y и размеры. Вращение поддерживает объекты с разными размерами по осям.
- ПКМ + мышь — осмотр; WASD — полёт, Q/E — вниз/вверх. Для клавиатуры нажмите на сцену.
- Добавление создаёт экземпляр выбранного шаблона. Копирование сохраняет ссылку на шаблон и индивидуальные изменения.
- Привязка: перенос — 1 м, размеры — 0,25 м, поворот — 15°. Размеры: 0,25–128 м, координаты: ±2048 м, до 2000 объектов.
- При выходе в игру персонаж возвращается на старт, чтобы не оставаться внутри изменённых зданий.
- Кнопка точки старта берёт последнюю позицию игрока; сначала дойдите до нужного места в игре.
- «Сохранить» записывает карту в localStorage этого origin. Перезагрузка её восстановит.
- Экспорт JSON — переносимая резервная копия. Импорт сначала проверяет весь файл, затем заменяет карту.
- Импорт и сброс не перезаписывают сохранение браузера до нажатия «Сохранить».
- Undo пока нет; экспортируйте карту перед большой переделкой. Очистка данных браузера удаляет сохранение.

## Устройство

- `src/main.ts` — сцена, камера, локальный ввод, анимации, интерфейс редактора.
- `src/player.ts` — шаг движения, гравитация и коллизии; не читает клавиатуру или DOM.
- `src/world.ts` — формат карты, проверка импорта, исходные кварталы, координаты ячеек.
- `public/models/` — локальный GLB и сведения об источнике и лицензии.

Симуляция идёт с шагом 1/60 секунды, длинные кадры ограничены 100 мс.
Столкновения используют встроенный эллипсоид Babylon, без отдельного физического движка.
Есть ожидание, ходьба, бег и прыжок. Переходы используют crossfade весов Babylon.js за 0,15 с
с плавной кривой smoothstep, независимо от FPS. Быстрые переключения продолжаются из текущей
смеси поз; после перехода ненужные клипы останавливаются. Реализация — `src/animationBlend.ts`.
Один источник света, общие однотонные материалы, без теней и текстур.

Карта состоит из девяти ячеек по 64 м. Во время игры активны соседние ячейки, в редакторе — все.
Это пока отключение готовых мешей, а не загрузка с диска или освобождение памяти.
Объекты имеют постоянные ID; формат карты не содержит камер, UI или анимаций игрока.

Сервера, сетевой синхронизации и бесконечного мира пока нет. Онлайн потребует авторитетной
серверной симуляции, проверки ввода, предсказания и интерполяции. Текущая структура разделяет
ввод и движение, но не гарантирует детерминизм физики между браузерами.
Производительность на целевом устройстве ещё нужно измерить; счётчик FPS — внизу экрана.

## Камера и препятствия

Камера использует spring arm: желаемый зум хранится отдельно от фактической позиции.
Приближение включается при полном перекрытии силуэта из желаемой позиции камеры:
все девять точек (голова, корпус, ноги × центр и края) должны быть закрыты.
Полупрозрачность включается от 40% перекрытия (минимум 4 из 9 точек). Простая близость
к препятствию ничего не включает. Проверка использует
непрозрачную геометрию независимо от временной прозрачности, чтобы эффект не выключал сам себя.

Минимальная дистанция от точки слежения за героем — 2,5 м, включая ручной зум и приближение
при перекрытии. Если стена ближе, минимальная дистанция имеет приоритет над коллизией камеры;
закрывающие героя объекты остаются полупрозрачными.

При полном перекрытии проверка учитывает радиус камеры 0,3 м и запас 4 см: камера быстро и плавно
приближается к рассчитанной дистанции и плавно возвращается к выбранному зуму после открытия
обзора. При внезапном перекрытии приближение тоже сглаживается (около 0,13 с на 90% пути),
поэтому на время перехода допускается пересечение с полупрозрачным препятствием.
Ограничение пола остаётся мгновенным, чтобы камера не уходила под землю. Прогноз движения на 120 мс действует только пока силуэт полностью закрыт; он не может
самостоятельно включить приближение при частичном перекрытии. Закрывающие силуэт объекты
становятся прозрачными до 25%. Когда перекрытие падает ниже 40%, их исходная
непрозрачность сразу восстанавливается. Земля не становится прозрачной. В редакторе и после
возврата на старт прозрачность сбрасывается.

`src/followCamera.ts` проверяет расширенные ориентированные коробки текущей карты.
Девять точек — дешёвая консервативная оценка силуэта, не попиксельная маска анимированной модели.
Для сложных вогнутых моделей потребуются физические sphere casts или более точные коллайдеры.
При частичном перекрытии отдельная защита от касания камеры стеной намеренно не срабатывает.
Вертикальное вращение допускает взгляд снизу до 18° относительно горизонта. Земля всегда
ограничивает камеру независимо от перекрытия героя: камера приближается, оставаясь над полом,
и плавно возвращается при освобождении пространства. Для непрозрачного пола защита от
проникновения имеет приоритет над обычным минимумом 2,5 м.

## Шаблоны и экземпляры

Карта версии 2 содержит `templates` и `objects`. Шаблон задаёт ID, название, категорию,
размеры по умолчанию и цвет. Экземпляр хранит собственный ID, `templateId`, позицию, поворот
и необязательные индивидуальные `size` / `color`. Размеры и цвет без переопределения наследуются
от шаблона. Позиция и поворот всегда принадлежат экземпляру. Категория принадлежит шаблону.

Исходный город собран из шаблонов зданий, земли и ступеней. Для коробочных шаблонов используется
`Mesh.clone()` Babylon: геометрия общая, трансформации и прозрачность индивидуальны. Это
переиспользование геометрии, а не объединение всех объектов в один draw call.

В редакторе:

- Выберите шаблон в каталоге и нажмите «Добавить».
- «Свойства шаблона» позволяет менять название, категорию, размеры и цвет. Применение обновляет
  связанные объекты, сохраняя их позиции и индивидуальные изменения.
- Изменение размера объекта манипулятором создаёт индивидуальное переопределение размеров.
- «Сбросить изменения» возвращает размер и цвет выбранного объекта к значениям шаблона.
- «Назначить шаблон» связывает выбранный объект с шаблоном из каталога и сбрасывает его
  индивидуальные размеры/цвет. Позиция и поворот сохраняются.
- «Новый шаблон из выбранного объекта» создаёт шаблон с текущими размерами и цветом объекта
  и связывает с ним выбранный экземпляр.
- Удалить можно только неиспользуемый шаблон; последний шаблон в каталоге сохраняется.
- Лимит каталога — 256 шаблонов. Экспорт/сохранение включает весь каталог.

Карты версии 1 из браузера и JSON автоматически преобразуются при загрузке: ID, позиции,
повороты, размеры и цвета сохраняются. Старые размеры/цвета становятся индивидуальными
переопределениями; чтобы объект наследовал свойства шаблона, нажмите «Сбросить изменения».
Ключ localStorage сохранён для совместимости. Новые сохранения/экспорты используют версию 2;
старая версия приложения их не прочитает.

Шаблоны пока состоят из коробки: импорт произвольных GLB-шаблонов, вложенные шаблоны и
наследование между шаблонами не реализованы.
